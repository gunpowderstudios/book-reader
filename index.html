☁ Syncing Playback

Use a small progress file to move your reading place between devices. No account or connection to EPub Reader is needed.

On the device you have been reading on

What is this file? It is a tiny plain-text note (a “JSON” file) that records which book you are reading and where you stopped. JSON is a standard, widely used format that apps, websites and phones everywhere use to store simple information. It is safe: it contains no program code, nothing in it can run or change your device, and it holds only your reading places. You can open it in any text editor to see for yourself.

Press Save Progress File, then save the file (named after your book, for example Book Title - reading progress.json) to Dropbox, iCloud Drive, Google Drive or another folder you can access on your other device.

Move your book and bookmark together

Save the current EPUB and your reading position in one file. On your other device, load that one file to continue. This is for books you are allowed to copy for your own use.

This is a manual transfer. The audio voice model is not included.

On your other device

Load the same EPUB, then press Load Progress File and select the saved file using your device's file picker.

Your current reading position is also saved automatically in this browser.

Please note: saving and loading are manual. The browser cannot automatically write back to the same cloud file on all devices. Saving again may create another downloaded copy; replace the old file in your cloud folder if needed. The EPUB itself must be on both devices.

This device may not support AI narration

Your device may not have enough available memory to run the voice engine. Please try a newer device or update your browser if an update is available. Switching browsers on the same older iPad may not help.

Choosing a suitable speed for this device…

⚙ Settings

Automatic chooses Fast for computers or Low Memory for phones and tablets. Fast may narrate quicker but uses more memory. Low Memory works better on many older devices. These are model download sizes, not total RAM usage. If a mode fails, the reader tries a lighter alternative. You normally don't need to change this.
